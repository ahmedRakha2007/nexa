# Nexa Social Hub

Build a modern social media frontend called Nexa.

Tech Stack

TypeScript

React Router

Axios

React Hook Form

General Requirements

Responsive design (mobile, tablet, desktop)

Clean, modern UI similar to Instagram, Threads, and X

Use reusable components

Use TypeScript everywhere

Follow a scalable folder structure

Keep the code clean and maintainable

Use dark mode as the default theme

Do not generate any backend code or mock API server

Design
